# Tractor wheel face

`steel_hub.png` was created with the built-in image generation tool. It is a
fixed opaque albedo map, packaged with the generator and copied to the export's
`textures/` directory. Circular UVs map it onto both sides of each dished rim.
The lug nuts and ventilation openings are texture details, not physical holes.
Tire sidewalls and chevron tread are procedural geometry so their silhouettes
and shadows respond to Isaac Sim lighting. No image service runs during export.
